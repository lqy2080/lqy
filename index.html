    5 分钟上手

    不需要安装软件，打开 HTML 就能制作和管理思维导图。

    ① 手动创建 点击“新建思维导图”，填写主题，可一次填写多个一级分支。选中节点后，用画布上方的按钮添加子分支、同级分支或编辑文字。蓝色的“节点减号＋上箭头”图标只删当前节点，保留全部下级并按原顺序提升一级；红色垃圾桶会连同所有下级一起删除。悬停可看说明，手机可在“更多 → 删除图标说明”中查看；两种操作都可撤销。点击上方“批量添加”，每行写一项，使用空格或粘贴的 Tab 缩进表示下级；确认预览后一次添加。也可切换成“每行同一级”。专注模式下可直接使用。“更多 → 样式与设置”中可修改备注、颜色和布局。

    ② 组织：拖动节点可移动或排序，也能用“上移/下移”。“更多 → 多选整理”可点选多个节点，再点“整理所选”统一移动或改色。移动保留整个分支，父子同时选中时不会重复搬移；完成后可以撤销。点“完成多选”或按 Esc 回到普通操作。

    搜索定位：在“更多 → 搜索当前导图”输入节点文字或备注关键词，点击结果即可展开所在分支并定位。结果只来自当前导图；展开动作可撤销。

    ③ 视图：点击顶部“专注模式”，收起导图列表、备份状态栏和次要工具，自动备份继续运行。左上角可临时展开列表，右上角“工具”可展开 AI、导入、导出；画布上方“更多”可打开搜索、多选和样式。点击“退出专注”恢复；Esc 会先关闭面板，再退出专注。拖动画布平移，双指或鼠标滚轮缩放，点击“全图”自动适配。画布顶部可一键“全部展开”所有层级，或“全部折叠”只保留一级目录；操作可撤销。

    ④ 电脑快捷键：Tab 添加子节点；Enter 添加同级；Delete 删除；⌘/Ctrl+Z 撤销；F2 编辑文字。输入时 Enter 保存，Shift+Enter 保存并添加同级，Tab 保存并添加子分支。

    ⑤ AI：首次填入 DeepSeek API Key 可勾选“记住此设备”，下次自动读取；共享设备请勿保存。默认优先使用 DeepSeek V4 Pro，也可在“AI 一键生成”或设置中切换到 Flash，模型选择下次打开仍有效。输入主题并点击生成。一级与各级子分支数量均由 AI 根据知识逻辑自主决定，不用手动规定。选中节点可选择“AI 扩展”，也会智能判断是否有必要添加。AI 生成不等于事实核查，专业内容请人工审核。

    ⑥ 备份：点击顶部“导出 → 全部导图 → 保存全部导图到手机”，下载一个可阅读、可恢复的 HTML 文件，再传到手机“文件”或网盘保管。恢复时点击“导入”选择该文件，先预览再恢复，现有导图会保留，重复内容会跳过。也可单独下载全部备份 JSON。“自动备份与历史记录”默认保存浏览器历史；建议首次选择备份文件夹，之后自动写入独立文件。浏览器历史会随清理网站数据删除，独立文件可从“导入”恢复。手动导出的阅读文件仍需重新导出才包含后续修改。

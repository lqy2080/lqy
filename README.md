# 我的第一个 GitHub 项目：待办清单

一个无需安装软件、没有依赖的中文网页小项目。通过它练习 GitHub 的基本操作。

## 先把项目运行起来

1. 在仓库首页点击绿色 **Code** 按钮 → **Download ZIP**。
2. 解压下载的压缩包。
3. 双击解压后的 **index.html**，用浏览器打开。
4. 添加一条任务、勾选完成，再刷新页面，看看记录是否保留。
5. 点“删除”可以移除任务。

任务只保存在当前浏览器的本地存储中，不会上传到 GitHub，也不会跨设备同步。某些浏览器对直接打开本地文件的存储有限制；如果出现保存提示，请留意数据可能不会保留。

**在 GitHub 点开 index.html 时看到的是源代码。要运行网页，请先下载并解压。**

## 这几个词是什么意思？

| 名称 | 简单理解 |
| --- | --- |
| Repository / 仓库 | 放代码和文档的项目文件夹。这个仓库叫 lqy。 |
| Commit / 提交 | 给修改保存一个有说明的版本，之后可以查看历史。 |
| Branch / 分支 | 从现有代码分出一条练习路线。默认分支叫 main。 |
| Pull request / PR | 把分支上的修改拿出来比较、讨论，再合并。 |
| Issue | 记录一个问题、想法或待做任务。 |

## 文件说明

- **index.html**：页面文字、结构和颜色。第一次练习修改这个文件。
- **app.js**：添加、完成、删除和保存任务的逻辑。
- **README.md**：你正在读的说明文档。

## 练习一：改一个标题，保存你的第一个版本

1. 在仓库里点击 **index.html**。
2. 点击右上角的铅笔图标（Edit this file）。
3. 找到 `<h1>我的待办清单</h1>`。
4. 改成 `<h1>我的学习计划</h1>`。
5. 点击 **Commit changes**，在说明里写“修改清单标题”。
6. 选择直接提交到 **main**，确认提交。
7. 返回仓库首页，点击文件列表上方的 **Commits / 提交记录**，找到这次修改。

**检查结果：**再次点开 index.html，应该能看到新标题。
如果要在浏览器里看新版网页，重新下载 ZIP 并解压，再打开新版 index.html。

## 练习二：用分支和 PR 修改一句话

1. 返回仓库首页，点击文件列表上方的 **main** 分支选择器。
2. 输入 `practice-description`，选择创建同名分支。
3. 在这个分支编辑 index.html，把“从一件小事开始”改成你喜欢的话，然后提交。
4. 点击仓库的 **Pull requests** → **New pull request**。
5. 确认 **base: main**，**compare: practice-description**。
6. 查看差异，点击 **Create pull request**，写清修改原因。
7. 创建后，点击 **Merge pull request** 并确认，把修改合并回 main。

**检查结果：**切回 main，确认文字已经更新。
自己的练习仓库可以自己审阅和合并 PR。

## 练习三：记录一个想法

1. 点击 **Issues** → **New issue**。
2. 标题写“给待办清单增加截止日期”。
3. 描述你希望它怎么工作，然后提交。
4. 不知道怎么实现时，把 Issue 链接发给 ChatGPT 继续练习。

Issue 是需求记录，创建它不会自动实现功能。若看不到 Issues 标签，可在仓库 Settings → General → Features 中启用。

## 你可以继续试试

- 修改 index.html 中的背景色 `#eef4ef`。
- 改变输入框的示例提示。
- 请 ChatGPT 给每条任务加上创建日期。

每次只改一个小地方，并写一句清楚的提交说明，会更容易看懂历史。

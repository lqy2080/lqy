# 梦想成真思维导图 · AI 版

在线使用：**https://lqy2080.github.io/lqy/**

本项目部署用户提供的单文件 HTML，页面内名称为“智图 AI · 思维导图工作台”。

## 使用方法

1. 打开上面的在线地址。
2. 首次打开可先点击“稍后设置”，以后再设置备份。
3. 点击“新建思维导图”开始手动编辑，也可以导入已有备份。
4. 使用页面的导出和备份功能保存重要内容。

## 数据和 AI

- 导图主要保存在当前浏览器本地，GitHub 不会自动同步你的编辑内容。
- 原本地 HTML 中保存在浏览器的数据不会自动迁移到在线网站，请先从原页面导出备份，再到网站导入。
- 手动编辑无需 API Key；AI 功能需要在页面中配置自己的 DeepSeek API Key 和额度。
- 不要把 API Key 写进代码或提交到公开仓库。
- 自动备份文件夹功能依浏览器支持情况而定；手机可使用导出备份。

## 文件

- `index.html`：用户提供的原始 HTML，包含页面、样式及脚本。
- `.nojekyll`：让 GitHub Pages 直接发布静态文件。
